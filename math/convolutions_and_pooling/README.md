# Convolutions and Pooling

This project covers convolution and pooling operations used in image
processing and convolutional neural networks.

## Learning Objectives

- Understand convolution
- Understand kernels and filters
- Understand padding
- Understand valid and same convolution
- Understand strides
- Understand image channels
- Perform convolution on images
- Perform max and average pooling

## Tasks

### 0. Valid Convolution

Perform a valid convolution on multiple grayscale images using NumPy.
