# Hyperparameter Tuning

This project covers hyperparameter tuning and Bayesian optimization.

## Learning Objectives

- Hyperparameter tuning
- Random search and grid search
- Gaussian Processes
- Mean and kernel functions
- Gaussian Process Regression
- Bayesian Optimization
- Acquisition functions
- Expected Improvement
- GPy and GPyOpt

## Task 0 - Gaussian Process

Implements a noiseless one-dimensional Gaussian Process using
the Radial Basis Function (RBF) kernel.
