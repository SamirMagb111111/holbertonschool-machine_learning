# Autoencoders

This project covers autoencoders using TensorFlow and Keras.

## Learning Objectives

- What is an autoencoder
- What is latent space
- What is a bottleneck
- What is a sparse autoencoder
- What is a convolutional autoencoder
- What is a generative model
- What is a variational autoencoder
- What is Kullback-Leibler divergence

## Task 0 - Vanilla Autoencoder

Implements a fully connected autoencoder composed of an encoder,
a latent space representation, and a decoder.
