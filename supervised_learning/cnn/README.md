# Convolutional Neural Networks

This project covers convolutional neural networks and their implementation
using NumPy, TensorFlow, and Keras.

## Learning Objectives

- Understand convolutional layers
- Understand pooling layers
- Perform forward propagation over convolutional layers
- Perform forward propagation over pooling layers
- Perform back propagation over convolutional layers
- Perform back propagation over pooling layers
- Build convolutional neural networks using TensorFlow and Keras

## Tasks

### 0. Convolutional Forward Propagation

Perform forward propagation over a convolutional layer using NumPy.
