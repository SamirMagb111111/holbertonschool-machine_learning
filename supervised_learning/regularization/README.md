# Regularization

This project covers regularization techniques used in machine learning and deep learning to reduce overfitting and improve model generalization.

## Learning Objectives

- Understand regularization and its purpose
- L1 regularization
- L2 regularization
- Dropout
- Early stopping
- Data augmentation
- Implement regularization techniques using NumPy and TensorFlow

## Tasks

### 0. L2 Regularization Cost

Calculate the cost of a neural network while accounting for L2 regularization.
