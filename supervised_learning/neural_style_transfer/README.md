# Neural Style Transfer

This project covers Neural Style Transfer using TensorFlow.

## Learning Objectives

- What is Neural Style Transfer
- What is a Gram matrix
- How to calculate style cost
- How to calculate content cost
- What is Gradient Tape
- How to perform Neural Style Transfer

## Task 0 - Initialize

Implements the NST class, validates style and content images,
sets the content and style weights, and preprocesses images by
resizing the largest dimension to 512 pixels and scaling pixel
values to the range [0, 1].
