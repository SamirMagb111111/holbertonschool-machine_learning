# Optimization

This project covers optimization techniques used in machine learning and deep learning.

## Learning Objectives

- Hyperparameters
- Data normalization
- Stochastic Gradient Descent
- Mini-batch Gradient Descent
- Moving averages
- Gradient Descent with Momentum
- RMSProp
- Adam optimization
- Learning rate decay
- Batch normalization

## Tasks

### 0. Normalization Constants

Calculate the mean and standard deviation of each feature in a dataset.
