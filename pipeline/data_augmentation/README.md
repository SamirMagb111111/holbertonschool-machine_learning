# Data Augmentation

This project covers data augmentation techniques used to increase the
diversity of training data and improve model generalization.

## Learning Objectives

- Understand data augmentation
- Know when to use data augmentation
- Understand the benefits of data augmentation
- Perform image transformations with TensorFlow
- Understand automated data augmentation

## Tasks

### 0. Flip

Horizontally flip an image using TensorFlow.
